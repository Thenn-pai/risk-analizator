# Анализатор рисков

Оконная программа для лабораторной работы по анализу угроз офисного подразделения ПАО «Ростелеком».

## Запуск

Установите Python 3 с Tkinter. В командной строке откройте папку с файлом и выполните:

```cmd
python risk_analyzer.py
```

## Работа с программой

- **Структура** — подразделение, подсистемы и объекты.
- **Угрозы и защита** — четыре угрозы, ущерб и меры из лабораторной работы № 4.
- **Оценка рисков** — введите вероятность и ущерб до и после мер, название варианта и стоимость. Нажмите «Добавить оценку».
- **Сравнение мер** — таблица и диаграмма исходного и остаточного риска. Для одного события можно добавить несколько вариантов. Суммировать варианты не следует.
- **Сохранить проект / Открыть проект** — сохранение и загрузка оценок в JSON.
- **Сформировать отчёт** — текстовый отчёт со структурой, угрозами и добавленными оценками; его можно открыть в Word.

Ожидаемый ущерб = ущерб × вероятность / 100. Для остаточного риска используются введённые значения ущерба и вероятности после мер. Вероятности, результаты действия мер и их стоимость вводятся пользователем; формулы и параметры необходимо сверить с материалами преподавателя. Данные не сохраняются автоматически.
