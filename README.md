# risk-analizator

Оконная программа для анализа угроз офисного подразделения ПАО «Ростелеком».

## Запуск

Установите Python с Tkinter. Откройте командную строку в папке с файлом и выполните:

```cmd
python risk_analyzer.py
```

Выберите угрозу, введите вероятность и снижение риска мерами защиты в процентах, затем добавьте запись в таблицу. Кнопка диаграммы сравнивает ожидаемый ущерб до и после мер. Отчёт сохраняется в CSV.

Ожидаемый ущерб = ущерб × вероятность / 100. Остаточный риск = ожидаемый ущерб × (1 − снижение / 100). Вероятность и снижение вводятся пользователем; правила расчёта необходимо сверить с материалами преподавателя. Данные таблицы сохраняются через CSV, автоматического восстановления при запуске нет.
