# Анализатор рисков

Оконная программа на Python с библиотекой Tkinter для практических работ № 7 и № 8.

## Запуск

Установите Python 3. Извлеките архив с программой и откройте командную строку в папке со всеми файлами:

```powershell
python .\risk_analyzer.py
```

Все файлы `.py` должны находиться в одной папке. Дополнительные библиотеки не нужны: используются компоненты стандартной библиотеки Python.

## Файлы программы

- `risk_analyzer.py` — исходные данные и запуск.
- `interface.py` — окно, вкладки и кнопки.
- `calculations.py` — расчёт и проверка введённых чисел.
- `project_io.py` — сохранение, открытие и проверка проекта JSON.
- `reporting.py` — формирование текстового отчёта.
- `dialogs.py` — окна редактирования угроз и описаний.

## Возможности

- «Структура»: дерево организации, добавление и удаление подразделений и объектов, отдельное описание выбранного объекта, выбор объекта для оценки.
- «Описание предприятия»: текстовое поле и кнопка «Вставить по шаблону». Названия и содержимое полей шаблона можно менять.
- «Угрозы и защита»: добавление, изменение и удаление угроз. В каждой записи можно редактировать объект, потери, уязвимости и меры защиты. Объект можно выбрать из структуры или ввести вручную; несколько уязвимостей и мер разделяются точкой с запятой.
- «Оценка рисков»: ввод потерь и вероятности до и после мер, их стоимости и сохранение оценки.
- «Сравнение мер»: таблица и диаграмма ожидаемого ущерба до и после выбранных мер.
- Описания, каталог угроз, структура и оценки сохраняются вместе в JSON и включаются в текстовый отчёт.

При смене объекта готовая сумма ущерба очищается, и её нужно ввести заново. Данные автоматически не сохраняются. Проекты из предыдущей версии остаются совместимыми.
Для сохранения новых данных используется формат проекта версии 3; прежние версии приложения его не открывают.

## Расчёт

Ожидаемый ущерб = потери за один инцидент × вероятность в процентах / 100. Остаточный показатель рассчитывается по введённым пользователем потерям и вероятности после мер. Стоимость мер показывается отдельно. Для этой модели вероятность задаётся на год, рассматривается не более одного инцидента за этот период. Параметры вводятся пользователем, а не загружаются как реальные статистические данные. Математическую модель необходимо сверить с материалами преподавателя.
