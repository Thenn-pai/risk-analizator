# Анализатор рисков

Оконная программа на Python с библиотекой Tkinter для практических работ № 7 и № 8.

## Запуск

Установите Python 3. Извлеките архив с программой и откройте PowerShell в папке со всеми файлами. Один раз установите библиотеки для диаграмм и отчёта Word:

```powershell
python -m pip install -r requirements.txt
```

Запустите программу:

```powershell
python .\risk_analyzer.py
```

Все файлы `.py` и `requirements.txt` должны находиться в одной папке. Интернет нужен для первой установки библиотек; после неё программа работает без подключения к интернету.

## Файлы программы

- `risk_analyzer.py` — исходные данные и запуск.
- `interface.py` — окно, вкладки и кнопки.
- `calculations.py` — расчёт и проверка введённых чисел.
- `project_io.py` — сохранение, открытие и проверка проекта JSON.
- `reporting.py` — формирование отчёта Word или текстового отчёта.
- `dialogs.py` — окна редактирования угроз и описаний.
- `risk_matrix.py` — диаграмма вероятности и тяжести последствий.
- `charts.py` — диаграммы по оценкам и матрице.
- `requirements.txt` — библиотеки для диаграмм и отчёта Word.

## Возможности

- «Структура»: дерево организации, добавление и удаление подразделений и объектов, отдельное описание выбранного объекта, выбор объекта для оценки. При переименовании объекта с уникальным названием оно меняется в связанных угрозах и оценках.
- «Описание предприятия»: текстовое поле и кнопка «Вставить по шаблону». Названия и содержимое полей шаблона можно менять.
- «Угрозы и защита»: добавление, изменение и удаление угроз. В каждой записи можно редактировать объект, потери, уязвимости и меры защиты. Объект можно выбрать из структуры или ввести вручную; несколько уязвимостей и мер разделяются точкой с запятой.
- «Оценка рисков»: ввод потерь и вероятности до и после мер, их стоимости и сохранение оценки.
- «Сравнение мер»: изменение сохранённой оценки, таблица и окно с несколькими диаграммами. Доступны полосовая, столбчатая и линейная диаграммы риска до и после мер, изменение риска и сопоставление вероятности с потерями.
- «Матрица рисков»: пользователь сам задаёт баллы P и I от 1 до 5, а программа строит диаграмму с номерами угроз. Эти баллы не вычисляются автоматически из процентов или суммы потерь.
- Описания, каталог угроз, структура и оценки сохраняются вместе в JSON.
- Кнопка «Сформировать отчёт» сохраняет `.docx` с данными, таблицами и диаграммами. При наличии точек матрицы добавляются матрица и круговая диаграмма их распределения по областям. Диаграммы Word построены по тем же введённым данным, что и на экране. Текстовый `.txt` можно сохранить отдельно, но изображения в нём отсутствуют.

При смене объекта готовая сумма ущерба очищается, и её нужно ввести заново. Данные автоматически не сохраняются. Проекты из предыдущей версии остаются совместимыми.
При закрытии программа предложит сохранить несохранённые изменения. Проект также сохраняет незавершённую форму оценки. Для новых данных используется формат проекта версии 4; прежние версии приложения его не открывают.

## Расчёт

Ожидаемый ущерб = потери за один инцидент × вероятность в процентах / 100. Остаточный показатель рассчитывается по введённым пользователем потерям и вероятности после мер. Стоимость мер показывается отдельно. Для этой модели вероятность задаётся на год, рассматривается не более одного инцидента за этот период. Параметры вводятся пользователем, а не загружаются как реальные статистические данные. Математическую модель необходимо сверить с материалами преподавателя.
